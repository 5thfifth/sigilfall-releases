# Sigilfall

Public Windows downloads and updates for Sigilfall, a card game played across five lanes.

Current version: **3.7.0 — A World Worth Playing**. Read the [release notes](https://github.com/5thfifth/sigilfall-releases/releases/tag/v3.7.0).

## Download and play

1. [Download the Windows starter zip](https://github.com/5thfifth/sigilfall-releases/releases/download/v3.0.0/Sigilfall-3.0.0-Windows.zip).
2. Extract the zip into a folder and keep its files together.
3. Open **Sigilfall Launcher.exe** and let it install the current update.
4. Select **PLAY SIGILFALL**.

The starter zip is labeled 3.0.0; its launcher brings the game up to the current version.

## Updating

Close the game, open **Sigilfall Launcher.exe** from your existing installation, let it install the update, then select **PLAY SIGILFALL**.

You can keep using the same installation for future updates.

## Releases

See [all releases](https://github.com/5thfifth/sigilfall-releases/releases) for published downloads and notes. The [launcher update channel](https://github.com/5thfifth/sigilfall-releases/releases/tag/channel) supplies updates automatically; use the launcher to install them.
